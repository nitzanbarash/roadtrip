# הטיול · ניו יורק ← מיאמי ← פיניקס

אפליקציית מפה לטלפון (אתר שמתנהג כמו אפליקציה). עובדת גם בלי אינטרנט.

- `docs/`: האפליקציה עצמה, כולל המפה המפורטת. מוגשת דרך GitHub Pages.
- `tools/`: הקוד שבונה את האפליקציה והמפה.
- `data/`: האטרקציות, הלינה והאירועים.

## להפעיל את האתר (פעם אחת)
GitHub ← הריפו ← **Settings** ← **Pages** ← Source: **Deploy from a branch** ← הענף `claude/rodetrip-attractions-trips-j88ibk` ← תיקייה **/docs** ← **Save**.
אחרי דקה-שתיים הכתובת מופיעה למעלה באותו עמוד (בערך `https://nitzanbarash.github.io/roadtrip/`).

## איך מתקינים באייפון (בלי App Store)
1. פותחים את הכתובת ב-**Safari** (לא בכרום).
2. **שיתוף** (הריבוע עם החץ) ← **הוספה למסך הבית** ← **הוסף**.
3. פותחים מהאייקון החדש. מעכשיו זה אפליקציה במסך מלא.
4. פעם אחת, עם וויפיי: **שכבות** ← "הורדה ושמירה בטלפון" לשני חלקי המפה (בערך 300MB). מאז המפה המפורטת עובדת גם בלי קליטה.
5. **כסף** ← הגדרות ← "סנכרון בין הטלפונים". בטלפון אחד מחברים Firebase (ההוראות שם), ושולחים לטלפון השני את **קישור ההצטרפות**. מי שפותח אותו מחובר, וכל שינוי מתעדכן אצל כולם.

## מה יש
- **לינה**: חיפוש מקום לישון לידי, בדרך קדימה או בעיר: אוהל, באוטו, קרוואן, מוטל, הוסטל. מהרשימה שלנו ומ-OpenStreetMap, ממוין מהזול. לכל מקום כפתור "איפה הכי זול להזמין".
- **דלק**: מחיר ממוצע בכל מדינה בדרך (AAA, מתעדכן כל יום), טיפ מתי למלא, כמה יעלה הדלק לשאר הדרך, והתחנות הזולות לידי.
- **מפה**: כל רחוב ודרך עפר לאורך המסלול, לוויין (באינטרנט), GPS ומצב נסיעה, מצפן. כמו בגוגל מפות: מקומות קטנים מופיעים רק כשמתקרבים, וחיפוש מראה הכול.
- **אטרקציות**: כ-2,000 מקומות, כולל עד 5 שעות מהמסלול, ולינה זולה וחינם בטבע. כל מקום אפשר לסמן כ"חובה" (זוהר במפה) ולהוסיף לתור.
- **התור**: העצירות שלנו בסדר שלנו. הקו הכחול משתנה ועובר דרכן.
- **אירועים**: לפי מדינה ותאריך, עם הערכה מתי אנחנו באזור. גם קטנים ומקומיים: ברים עם הופעות, שווקי איכרים, פסטיבלים של העיירה. ו"מה יש הערב לידי".
- **כסף**: מי שילם, מי חייב למי, עוגות וטבלאות, תקציב אישי. מסתנכרן בין שני הטלפונים.

## הכלים
- `tools/map/`: `ovt_extract.py` (שליפה מ-Overture Maps, כולל דרכי עפר), `split_pmtiles.py`, `package.py`, `build3.py` + `template3.html` + `app.js` / `ext.js` / `markers.js` (בניית האפליקציה), `live.js` / `live.css` (לינה, דלק, הורדת המפה, סנכרון), `patch_site.py` (מעדכן את `docs/index.html` מהקוד בלי בנייה מלאה), `icons.py` (הסמלים).
- `tools/fuel/fetch_fuel.py` + `.github/workflows/fuel.yml`: מחירי הדלק, פעם ביום.
- `tools/fin/`: מסך הכסף. `tools/finance.html`: אותו מסך כדף Claude.
- `tools/trip/`: מיזוג האטרקציות (`build2.py`).
